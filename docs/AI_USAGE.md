# AI Usage

## Overview

AI was used as a development aid during this assessment, mainly to speed up implementation within the limited timeframe.

Before generating code, I provided the project requirements along with the stack, folder structure, naming conventions, validation approach, API response format, and architectural guidelines. That gave the AI a defined direction to follow instead of leaving project decisions open-ended.

## How AI Helped

AI was mainly used for:

- generating initial implementations from the provided architecture
- handling repetitive TypeScript, Express, React, and Redux syntax
- creating boilerplate for controllers, services, repositories, validation, and tests
- troubleshooting dependency, build, and configuration issues
- helping organize and refine project documentation

## Development Process

For each feature, I first defined the expected behavior, data relationships, request flow, and important edge cases. I then gave that context to the AI and used its output as a starting point.

I reviewed the generated code, adapted it to the existing codebase, and checked that it followed the project conventions before keeping it. The final architecture, data model, feature behavior, and implementation decisions remained my responsibility.

## Verification

The final implementation was verified through:

- manual code review
- frontend and backend linting
- TypeScript builds
- backend automated tests
- manual testing of the main application flows

AI helped accelerate implementation, while the project requirements, technical direction, review, and final verification remained under my control.

## Known Limitations

- AI-generated output still needed review for correctness, consistency, and scope.
- Some suggestions were useful as drafts but still required rewriting to fit the actual project structure.
- Documentation in particular needed careful editing so that claims stayed proportional to the implemented system.
